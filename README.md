🫧 Bubble Pop Mania
Pop • Score • Beat the Clock!

Bubble Pop Mania is a fun and interactive bubble-popping arcade game designed to test players' speed, focus, and reaction time. Colorful bubbles appear randomly on the screen, and players must click or tap them to earn points before the countdown reaches zero.

As the game progresses, the bubbles appear faster, making the challenge more exciting!

🎮 Game Features
- Interactive Gameplay – Click or tap colorful bubbles to earn points.
- Scoring System – Earn 10 points for every bubble popped.
- Countdown Timer – Complete the game before the 30-second timer runs out.
- Increasing Difficulty – Bubble spawning speed increases as the game progresses.
- Sound Effects – Enjoy popping and end-game sounds.
- Sound Controls – Turn game sounds ON or OFF.
- Best Score – Automatically saves your highest score using Local Storage.
- Player Registration – Enter your player name for the leaderboard.
- MySQL Database – Saves player names and scores.
- Leaderboard – Displays the top 10 players.

🏆 How to Play
1. Click the Start Game button.
2. Colorful bubbles will randomly appear.
3. Click or tap each bubble to earn 10 points.
4. Try to pop as many bubbles as possible.
5. Watch the countdown timer.
6. When time runs out, your final score will be displayed.
7. Enter your player name to save your score.
8. Check the leaderboard and challenge yourself to get a higher score!

🎯 Project Objective
The main objective of Bubble Pop Mania is to provide an entertaining gaming experience while improving players' focus, speed, and reaction time.

The project also demonstrates the integration of frontend technologies, JavaScript game mechanics, PHP backend processing, and MySQL database management.
